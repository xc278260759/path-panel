# 路径面板

Windows 桌面小工具：把常用路径、文本、图片收进一个无焦点浮窗，呼出后双击或回车直接粘回目标输入框。

## 热键

- `Win+Alt+V`：呼出 / 收起面板
- `Win+Alt+C`：收藏当前选中内容（选中文本 / 选中的文件 / 剪贴板图片）
- `F2`：打开可输入的搜索窗（支持中文输入法），`Enter` 应用，`Esc` 取消

## 行为要点

- 面板用 `WS_EX_NOACTIVATE`，呼出时不抢前台，资源管理器地址栏不会退出编辑模式。
- 按 `Win+Alt+C` 会先向当前前台窗口发一次 `Ctrl+C` 取选中内容，读完立刻还原原剪贴板。
- 收藏分三类：`path` / `text` / `image`，原样保存，不做内容过滤。
- 去重：同一路径不区分大小写、忽略末尾斜杠与引号；文本中的路径与 path 条目互认；图片按内容 MD5 比对。
- 点击面板外任意位置自动收起。
- 托盘菜单：显示面板、从剪贴板添加、双击自动回车确认、设置、开机自启、退出。
- 确认白名单：总开关关闭时，白名单进程（默认 `explorer.exe`）仍会回车确认。

## 文件

| 文件 | 说明 |
| --- | --- |
| `路径面板.pyw` | 主程序（Python 3.7 + tkinter + pystray） |
| `路径面板.ico` | 图标 |
| `build_路径面板.bat` | PyInstaller 打包脚本 |
| `路径面板_说明.md` | 早期使用说明 |

运行数据不在仓库里：

- 配置与收藏：`%APPDATA%\路径面板\paths.json`
- 图片：`%APPDATA%\路径面板\images\`
- 日志：`%APPDATA%\路径面板\log.txt`

## 构建

```
build_路径面板.bat
```

产物：`dist\路径面板.exe`（onefile，约 27 MB）。分发时复制到 `F:\路径面板\路径面板.exe`。

## 仓库约定

`.gitignore` 采用白名单：只有上表文件入库。新增源文件时需要把文件名加进 `.gitignore` 的 `!` 列表。
