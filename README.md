# 路径面板

Windows 桌面小工具：把常用路径、文本、图片收进一个无焦点浮窗，呼出后双击或回车直接粘回目标输入框。

当前版本：**v0.2.0**

## 热键

- `Win+Alt+V`：呼出 / 收起面板
- `Win+Alt+C`：收藏当前选中内容（选中文本 / 选中的文件 / 剪贴板图片）
- `F2`：打开可输入的搜索窗（支持中文输入法），`Enter` 应用，`Esc` 取消

## 行为要点

- 面板用 `WS_EX_NOACTIVATE`，呼出时不抢前台，资源管理器地址栏不会退出编辑模式。
- 按 `Win+Alt+C` 会先向当前前台窗口发一次 `Ctrl+C` 取选中内容，读完立刻还原原剪贴板。
- 收藏分三类：`path` / `text` / `image`，原样保存；面板用三个页签分别展示，搜索跨类型命中并标注类型前缀。
- 排序：路径页按盘符分组（`C:` / `D:` …，UNC 归“网络”），文本/图片页按首字母（中文取拼音）。
- 分组显示可在设置里切换：`盘符/字母标题`（默认）或 `彩色整块`（不显示文字，用整组底色 + 左侧色条区分盘符，颜色按 A–H 固定映射）。
- 去重：同一路径不区分大小写、忽略末尾斜杠与引号；文本中的路径与 path 条目互认；图片按内容 MD5 比对。
- 点击面板外任意位置自动收起。
- 滚动条为自绘 Win10 深色样式（箭头翻页、直角滑块、悬停提亮）。
- 托盘菜单：显示面板、从剪贴板添加、双击自动回车确认、设置、开机自启、退出。
- 设置窗口：路径/文本/图片三个标签，列表极简（只有缩略图或内容，缺文件才标“缺失”），切换标签不改变窗口尺寸。
- 确认白名单：总开关关闭时，白名单进程（默认 `explorer.exe`）仍会回车确认。

## 文件

| 文件 | 说明 |
| --- | --- |
| `路径面板.pyw` | 主程序（Python 3.7 + tkinter + pystray + pypinyin） |
| `路径面板.ico` | 图标 |
| `路径面板.spec` | PyInstaller 配置（含 pypinyin hiddenimports） |
| `build_路径面板.bat` | PyInstaller 打包脚本 |
| `路径面板_说明.md` | 使用说明 |

运行数据不在仓库里：

- 配置与收藏：`%APPDATA%\路径面板\items.json`（旧 `paths.json` 首次启动自动迁移）
- 图片：`%APPDATA%\路径面板\images\`
- 日志：`%APPDATA%\路径面板\log.txt`

## 构建

依赖（Python 3.7）：`pip install pyinstaller pystray pillow pypinyin`

```
build_路径面板.bat
```

产物：`dist\路径面板.exe`（onefile，约 27 MB）。分发时复制到 `F:\路径面板\路径面板.exe`。
